# VersaLife Health — gateway landing

Hub landing page for [versalifehealth.com](https://versalifehealth.com): routes visitors to **Shop**, **Telemedicine**, and **E-Channeling**.

Design source: Google Stitch export in `stitch_versalife_health_gateway/`.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Service URLs

Edit `lib/services.ts` to change destination URLs and copy.

## Stack

Next.js 15, React 19, Geist + Newsreader typography, CSS aligned to the Clinical Daylight Minimal tokens in `stitch_versalife_health_gateway/clinical_daylight_minimal/DESIGN.md`.
